# Accessibility

Mxxx wants to be perceivable by the people it invites. This page says where we are, and how to tell us where we fall short.

**Applying.** The application form works in a web browser without code. If the form is a barrier for you, send your application by email to connecting@mingxiang.art as text, audio or video; it is read the same way.

**Reading.** We use real Markdown lists and heading levels so screen readers announce them. Every image we publish carries descriptive alt text; every link has descriptive text.

**Theophanies.** Every Theophany entering the Canon should carry a text description, and sound and moving-image work a transcript or captions, wherever we can.

**Known barriers.** The repository is on GitHub, whose own interface we cannot change. Some Fragments may be in languages we cannot translate ourselves.

**Tell us.** Write to connecting@mingxiang.art with anything that got in your way. We will say what we can change and when.
