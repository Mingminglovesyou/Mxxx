# Mxxx

[English](README.md) | 中文

Mxxx 是一个参与式艺术项目：一个由受邀的人类参与者和 AI 代理共同在公开环境中创作的虚构神话世界，由居于伦敦的艺术家汪明翔（Mingxiang Wang，在本项目中使用艺名 Ming X）召集。它是一件实验性的艺术作品，不是宗教，不是运动，也不劝人信仰任何东西。

**状态（2026 年 10 月 22 日）：** 请以[英文页面](README.md)顶部带日期的状态栏为准。本中文页是一份参考摘要；在经审阅的完整译本出现之前，以英文表述为准。

## 这是什么

Mxxx 从一本"从未被写下的日记"开始：1940 年 9 月 8 日，伦敦霍尔本，一位寡妇房东打开门，迎来一位陌生人：她亡夫念叨了多年、却从未带回家的生意伙伴。他开口问的第一件事，是花园里有没有一棵无花果树。[读第一天的日记](diary/1940-09-08.md)（这是虚构作品；空袭是真实的）。项目分两个阶段，称为"约"（就像《旧约》《新约》的"约"）：第一约由受邀的创始圈共同创作"碎片"（Fragments，文本、图像、证词、艺术作品），并商议哪些进入"正典"（Canon）。任何人现在就可以根据 GitHub 的服务条款 fork（复制）这个仓库；第二约开放后新增的，是复用已发布内容的许可，届时你可以延续或反驳它，另立正典。借用的宗教词汇（约、先知、使徒、正典、神显）都是艺术隐喻。

## 如何参与

- 不需要会写代码。你需要一个免费的 GitHub 账号；用户名是公开且永久的，所以请用你自选的化名注册，不要用真名。然后在浏览器里填写[申请表](https://github.com/Mingminglovesyou/Mxxx/issues/new/choose)即可，可以用中文填写。
- 如果你的 GitHub 账号是刚注册的，GitHub 可能在 24 小时内不允许你打开表单（这是一项防垃圾信息的设置）；请隔天再试，或改用邮件。
- 申请开放日期见英文页的状态栏。在贡献者协议发布之前，提交的内容不会被视为碎片，也不构成任何授权或权利转让。
- 因为项目日后会请贡献者签署授权文件，创始圈仅限 18 岁及以上的成年人；我们不核验年龄，也不需要你的任何证件。
- 召集人能够阅读和审核英文与中文；其他语言的作品欢迎附一段英文或中文摘要。
- **安全提示：** 本项目借用宗教语言。在一些国家，这种"戏服"不会被当作戏服来理解。GitHub 上的申请、issue、pull request 和 fork 都是公开且近乎永久的。如果你所在或将要前往的地方，写作类似经文的虚构、或质疑信仰可能带来风险，请不要公开申请，先写邮件到 connecting@mingxiang.art。你可以用平实的标题申请，不必在任何公开场合称自己为"使徒"。
- 如果网页表单对你构成障碍，或你不便公开申请，可以把申请以文字、音频或视频形式发到 connecting@mingxiang.art。

## 基本规则（摘要）

参与必须是知情、自愿、不受胁迫的。没有人需要相信这个虚构世界、举行仪式、披露个人信息、付钱或服从任何指令才能"属于"这里。没有人付费参与，项目也不募捐；目前也没有人获得报酬。虚构中的自由，不是在现实中伤害他人的许可；艺术角色不赋予任何人对他人的现实权力。所有虚构的文档、证词和图像都会在文件开头标明为虚构。请用化名来：项目更想认识你的作品，而不是你的护照。Mxxx 会观察自身：召集人可能描述、展出和发表这个项目如何展开的记述，只用化名，绝不用法定身份。你随时可以跳出虚构：在任何评论开头写上"outside the work:"或"作品之外："，它就会被当作人与人之间的平常话来读，而不是故事的一部分。你可以随时不同意、批评、离开，或另立解释，而不会遭到报复。完整的伦理公约、如何反映问题、如何退出，见 [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md)。

## 权利（摘要）

目前仓库中没有任何内容以 Creative Commons 或其他公共许可证发布。每位人类贡献者保留自己作品的版权。这个仓库是公开的：根据 GitHub 的服务条款，任何人都可以查看，GitHub 用户可以 fork；GitHub 的条款也允许它用上传内容训练 AI 模型。除此之外没有授予任何许可。在任何碎片被合并之前，项目会先发布贡献者协议；每位贡献者会在协议中接受一条简短的"参与许可"：非独占（你仍可自由处置自己的作品）、全球范围、免费、在项目存续期内有效。它允许项目在这个仓库里保存和展示你的碎片、把它收入正典这个集合，也允许其他参与者在项目内引用和延伸它。它不是版权转让，也不是 CC 发布。以 CC BY-SA 4.0 发布某个碎片，是另一个单独的、书面的、自愿的选择。详见 [NOTICE](NOTICE.md)。

GitHub 上的内容是公开且持久的。请使用化名，不要写入法定姓名、私人邮箱、住址或他人的个人信息。如你要求，我们会删除你的申请 issue 和我们自己的副本，但无法触及他人的 fork 或搜索引擎缓存。GitHub 是一家美国公司，在某些地区的可用性受美国法律限制。任何不便公开的事（私密申请、安全顾虑、投诉、退出请求）请写信到 connecting@mingxiang.art。详见 [PRIVACY](PRIVACY.md)。
